# minesweeper\_auto\_solver



Auto solves minesweeper games by setting mine tiles as flags. Works for classic minesweeper (SHA256: BCFF89311D792F6428468E813AC6929A346A979F907071C302F418D128EAAF41), which can be found on archive.org.


1. Start minesweeper.
2. Execute the solver.
3. Click any tile.
